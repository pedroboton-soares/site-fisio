# Documentação, Site da Fisioterapeuta

## 1. O que é o site

Site de divulgação profissional para uma fisioterapeuta com atendimento domiciliar em Palotina-PR e região, apresentando especialidades, forma de atendimento e canal de agendamento via WhatsApp.

## 2. Como instalar e rodar

Não precisa de instalação. Basta dar dois cliques no arquivo `index.html`. É necessário estar conectado à internet para carregar a biblioteca de efeito visual (via CDN).

## 3. Tecnologias, com versão, e o que cada uma faz

| Tecnologia | Versão | O que faz |
|---|---|---|
| HTML5 | - | Estrutura do site (seções, textos, imagens) |
| CSS3 | - | Aparência (cores, layout, responsividade) |
| JavaScript | - | Comportamento (menu mobile, rolagem suave, validação do formulário) |
| AOS (Animate On Scroll) | 2.3.1 | Faz os cards de especialidade e as fotos da galeria aparecerem suavemente conforme a página rola |

## 4. Revisão dos elementos que compõem o site

- **HTML** é a estrutura: define as seções (cabeçalho, sobre, especialidades, como funciona, região de atendimento, galeria, pagamento, contato, rodapé) e o conteúdo de cada uma.
- **CSS** é a aparência: aplica a paleta de cores (azul petróleo, verde água, coral), a tipografia, o espaçamento e a responsividade para celular.
- **JavaScript** é o que reage à ação do usuário: abre/fecha o menu no celular, faz a rolagem suave entre seções, valida se os campos obrigatórios do formulário foram preenchidos, e ativa os efeitos da biblioteca visual.
