## 2. Paleta de cores

Sugestão pensada para saúde/fisioterapia domiciliar: transmitir confiança e acolhimento, sem parecer clínico/frio demais.

| Cor | Hex | Uso |
|---|---|---|
| Azul petróleo | `#1E5F74` | Cor principal, cabeçalho, botões |
| Verde água suave | `#7FB3A0` | Detalhes, ícones, destaques |
| Branco gelo | `#F8F9FA` | Fundo principal |
| Cinza-chumbo | `#333333` | Texto |
| Coral suave | `#F2A488` | Botão de call-to-action (agendar) — cor de contraste |

## 3. Restrições (o que a IA NÃO pode fazer)

1. Não copiar texto de nenhum dos sites de referência, nem imagens de banco de imagens sem licença de uso comercial.
2. Não inventar depoimentos de pacientes reais — se usar depoimento de exemplo, marcar claramente como placeholder.
3. Não usar fotos de pessoas reais sem autorização — usar apenas fotos fornecidas pela Luana ou banco de imagens gratuito (ex: Unsplash, Pexels) com créditos anotados aqui.
4. Não adicionar seções fora da lista de requisitos (sem login, sem carrinho, sem chat automático).
5. Não usar bibliotecas que exigem servidor/Node para rodar — só HTML, CSS, JS puro + biblioteca de efeito via CDN.
